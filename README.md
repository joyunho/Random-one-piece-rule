# Random-one-piece-rule

원피스 랜덤 룰 뽑기 프로그램 (윈도우 exe)

메인 컨텐츠를 뽑으면 그 컨텐츠에 딸린 **추가 뽑기까지 한 번에** 끝내 줍니다.

---

## exe 받는 방법

### 방법 1 — 저장소에서 바로 받기 (제일 빠름)

**[release/랜덤원피스룰.exe](release/랜덤원피스룰.exe)** 를 열고 **Download raw file**
(⭳ 아이콘) 클릭. `main` 에 새 커밋이 올라갈 때마다 이 파일이 자동으로 최신 버전으로
갱신됩니다 — Actions 를 뒤질 필요가 없습니다.

### 방법 2 — GitHub Actions 에서 받기

1. 이 저장소의 **Actions** 탭 → **build-exe** 워크플로 선택
2. 최근 실행 결과 클릭
3. 아래쪽 **Artifacts** 의 `랜덤원피스룰-exe` 다운로드 → 압축 풀면 `랜덤원피스룰.exe`

(방법 1 과 내용은 같습니다. Actions 실행 기록별로 따로 받고 싶을 때만 이 방법을 쓰세요.
Artifacts 는 90일이 지나면 만료되지만, 방법 1 의 저장소 파일은 계속 남아 있습니다.)

### 방법 3 — 내 컴퓨터에서 직접 만들기 (파이썬 자동 설치)

이 폴더의 **`install_and_build.bat` 더블클릭** 한 번이면 끝입니다.
파이썬이 없으면 `winget` 으로 알아서 설치하고, PyInstaller 설치 → 빌드 → 이름 변경까지 진행합니다.
설치 중에 윈도우 권한 팝업이 뜨면 허용해 주세요. 결과는 `dist\랜덤원피스룰.exe`.

`cmd` 에 붙여넣어서 돌리고 싶으면 — 폴더 주소창에 `cmd` 입력 후 엔터, 그리고 아래 한 줄:

```
install_and_build.bat
```

**파이썬이 이미 깔려 있다면** `build_exe.bat` 을 써도 됩니다 (설치 단계만 빠진 버전).

> `python --version` 이 버전 없이 `Python` 한 줄만 찍히면, 실제 파이썬이 아니라
> 윈도우에 기본 포함된 **Microsoft Store 연결용 껍데기 `python.exe`** 입니다.
> 그래서 두 배치 모두 `where python` 만 보지 않고 **실제로 실행해 봐서** 판별합니다.

**창이 떴다가 바로 닫힌다면** — 두 배치 모두 이제 에러 메시지를 띄우고 멈춥니다.
그래도 닫힌다면 폴더 주소창에 `cmd` 를 치고 엔터 → `build_exe.bat` 을 입력해서 실행하면
메시지가 남습니다. 빌드 중 오류는 같은 폴더의 `build_log.txt` 에 기록됩니다.

> `build_exe.bat` 은 **CRLF 줄바꿈 + 영문 전용**으로 되어 있어야 합니다.
> LF 로 저장되면 윈도우 cmd 가 `goto` 라벨을 못 찾아서 창이 그냥 닫힙니다.
> `.gitattributes` 에서 `*.bat -text` 로 고정해 두었습니다.

### 그냥 소스로 실행

```
python main.py
```

| 탭 | 하는 일 |
|---|---|
| **메인 뽑기** | 15개 메인 컨텐츠 중 하나를 뽑고, 추가 뽑기까지 진행 |
| **등급 뽑기** | 초월 / 불멸 / 영원 / 제한 / 신비 중에서 한 마리 (4명 각각도 가능) |
| **강원랜디** | 18개 확률표를 보면서 단독으로 돌리기 |
| **캐릭터 관리** | 전설 / 히든 / 상위 / 랜덤·콜라보 이름 목록 등록 |
| **설정** | 컨텐츠 on/off·가중치, 숫자 범위, 강원랜디 확률표 편집 |
| **기록** | 이번 판에 뽑은 내용 전부 보기 / 복사 / 파일 저장 |

### 방송 출력 창 (OBS)

오른쪽 위 **[방송 창 열기]** 를 누르면 결과만 크게 나오는 별도 창이 뜹니다.
OBS 에서 이 창을 캡처하면 됩니다.

- 버튼·설정·파일 경로가 **전혀 나오지 않습니다** (방송에 사용자명 노출 방지)
- 운영자 창에서 뽑을 때마다 자동으로 따라 바뀝니다
- 색깔별 결과는 **똑같은 크기의 카드 네 장**으로, 값 하나가 정해질 때마다 번쩍입니다
- 글자는 **창 크기에 맞춰 자동으로 줄바꿈**됩니다. 창을 줄이거나 전체화면으로 키워도
  양옆이 잘리지 않습니다
- 강원랜디의 **확률(%)은 방송 화면에서 빠집니다** — 미션 이름과 숫자만 크게 나옵니다
- **F11** 전체화면, **Esc** 해제
- [설정] 탭에서 **1280x720 / 1920x1080** 프리셋과 **크로마키 배경(초록)** 선택

## 메인 컨텐츠와 추가 뽑기

15개 컨텐츠입니다. **검증** 칸은 실제 영상에서 룰을 어디까지 확인했는지를 뜻합니다
(자세한 건 [검증 상태](#검증-상태) 참고).

| 컨텐츠 | 검증 | 추가 뽑기 |
|---|---|---|
| **너의상위는** | 영상 확인 | 🎰 색깔별 `1~5`. `1~4` 는 그만큼 상위 상승, **`5` 는 0상위** |
| **이캐릭들필수에요** | 영상 확인 | 🎰 전설 4칸 · 히든 4칸, 칸마다 버튼 |
| **이캐릭들금지에요** | 영상 확인 | 🎰 전설 7칸 · 히든 7칸, 칸마다 버튼 |
| **필수!랜덤유닛획득** | 영상 확인 | 🎰 색깔별로 랜덤/콜라보 유닛 하나씩 (서로 겹치지 않음) |
| **개인미션전** | 영상 확인 | ☑ 색깔별 비밀 미션 3개, 실패 1개당 유카 +10 |
| **녜힁제조기** | 일부 확인 | 🎰 상위 이름에서 2글자 (아래 설명) |
| **인생의고도전** | 일부 확인 | 🎰 색깔별 `10~20`. 졸업보상 꼴찌 1명만 추가 추첨 |
| **강원랜디** | 일부 확인 | 🎰 색깔별로 18개 확률표에서 하나씩 |
| **4인 강제전** | 미확인 | 🎰 상위 중 한 마리 → 4명 모두 그 상위로 강제 |
| **지츠'다이스'룰** | 미확인 | 🎰 등급별 상위 1마리씩 + 색깔별 주사위(1~100) |
| 스토리 폭격기전 | 미확인 | — |
| 원딜전(물1마1) | 미확인 | — |
| 변질된 악몽 | 미확인 | — |
| 신비한이세계전 | 미확인 | — |
| 랜덤항법전 | 미확인 | — |

> 🎰 표시가 붙은 컨텐츠는 **버튼을 하나씩 눌러서** 뽑습니다.
> 숫자·이름이 촤르륵 돌다가 효과음과 함께 멈춥니다. (효과음은 윈도우에서만 납니다)

결과가 공개되는 순서는 **빨강 → 보라 → 파랑 → 노랑** 입니다.

### 검증 상태

컨텐츠마다 결과창 설명 왼쪽에 배지가 붙습니다.

| 배지 | 뜻 |
|---|---|
| **영상 확인** | 영상에서 규칙 문장과 적용 장면까지 확인 |
| **일부 확인** | 핵심 규칙은 확인, 일부 수치·예외는 미확인 |
| **미확인** | 해당 영상은 있지만 세부 룰을 확인하지 못함 — **기본으로 꺼져 있습니다** |

**미확인 컨텐츠는 처음 켜면 뽑기 대상에서 빠져 있습니다.** [설정] 탭에서 켜면 뽑힙니다.
값을 지어내지 않으려고 이렇게 해 뒀으니, 아는 룰이 있으면 [설정] 탭에서 설명과 숫자를
직접 채워 넣고 켜서 쓰세요.

### 너의상위는

색깔마다 **`1~5`** 를 뽑습니다.

- `1~4` → 나온 숫자만큼 상위를 올립니다
- **`5` → 상위 없음(0상위)** — 눈금이 뜬 뒤 한 박자 쉬고 `5 → 상위 0 (없음)` 이 뜨면서
  놀리는 소리가 납니다

### 필수!랜덤유닛획득

색깔마다 **랜덤/콜라보 유닛을 하나씩** 배정받고, 그 유닛을 반드시 만들어야 합니다.
네 명이 서로 다른 유닛을 받습니다.

만든 뒤 **상위 재료로 소비해도 인정**되고, 그 외 상위 선택은 자유입니다.
후보 명단은 [캐릭터 관리] 탭의 **랜덤/콜라보** 칸에서 고칠 수 있습니다.

### 개인미션전

색깔마다 **비밀 미션 3개**를 받습니다. 미션 내용은 각자만 알기 때문에 프로그램이
뽑아 주지 않고, **실패 체크와 유카 계산만** 해 줍니다. 실패 1개당 **유카 +10**.

이름은 "개인"미션전이지만 **경기 자체는 팀전**이고, 종료 후 각자 미션을 공개해서
대조합니다. 미션 개수와 유카 값은 [설정] 탭에서 바꿀 수 있습니다.

### 녜힁제조기

1. 상위 이름에 들어 있는 글자 중에서 **2글자**를 뽑는다 (글자마다 버튼)
2. 그 글자가 이름에 포함된 **상위를 전부** 보여준다 (2마리를 넘어도 다 나옴)
3. 거기 뜬 상위들만 써서 클리어한다

주사위도, 등급별 랜덤 픽도 없습니다.

> 예) `로`, `규` 가 나오면 → `로쿠규초월`, `로우초월` 처럼
> 이름에 `로` 나 `규` 가 들어간 상위만 사용

최소 한 마리는 나와야 하므로 **[캐릭터 관리] 탭에 등록한 상위 이름에 실제로 들어 있는 글자만** 후보가 됩니다.
`초월/불멸/영원/제한/신비` 같은 등급 글자는 뽑기 후보에서 제외됩니다
(안 그러면 `초` 하나로 초월 전부가 걸리기 때문). 이 제외 목록은 [설정] 탭에서 바꿀 수 있습니다.

### 인생의고도전

색깔마다 카드가 하나씩 있고, **[고도 뽑기]** 로 **`10~20`** 을 뽑습니다.
옆의 세로 막대(기구)가 고도만큼 올라갑니다.

**졸업보상을 가장 늦게 받은 1명**만 추가 추첨을 한 번 더 합니다. 운영자가 패널에서
그 사람을 지정하면 그 색깔의 **[추가 고도]** 버튼만 열립니다.

> 추가 추첨의 숫자 범위는 영상에서 확인하지 못했습니다. 그래서 **기본값이 비어 있고
> [추가 고도] 버튼이 잠겨 있습니다.** 임의로 채우지 않았으니, 아는 범위가 있으면
> [설정] 탭에서 넣어 주세요. 넣는 순간 버튼이 열립니다.

### 룰 설명

컨텐츠가 뽑히면 **결과창 맨 위에 검증 배지와 그 룰의 설명**이 뜹니다.
설명은 **[설정] 탭의 각 컨텐츠 줄에서 직접 고칠 수 있습니다.**

규칙을 확인하지 못한 **스토리 폭격기전 · 원딜전 · 변질된 악몽 · 신비한이세계전 ·
랜덤항법전** 5개는 설명이 비어 있습니다. 지어내지 않고 비워 뒀으니,
[설정] 탭에 직접 적어 두시면 결과창에 나옵니다.

### 효과음과 그림

- 효과음은 **윈도우에서만** 납니다. 외부 파일 없이 프로그램이 직접 소리를 만듭니다.
  메인 뽑기 화면의 **[효과음]** 체크로 끌 수 있습니다.
- 등급 문양은 프로그램이 직접 그립니다. 유닛 그림을 쓰고 싶으면
  설정 파일 옆에 `이미지` 폴더를 만들고 `루피.png` 처럼 넣어두면 자동으로 붙습니다.
  (`루피 (초월).png` 처럼 등급까지 붙인 이름도 인식합니다)

### 강원랜디 확률표

메인 뽑기에서 강원랜디가 나오면 **색깔마다 하나씩** 뽑습니다.
숫자 범위가 붙은 결과(`변이횟수 0~3` 등)는 범위 안에서 숫자까지 같이 뽑습니다.

**[캐릭터 관리] 탭**에서 언제든 고치고 **저장**하면 됩니다. 한 줄에 이름 하나씩이고,
고친 내용이 기본 명단보다 우선합니다. 목록을 통째로 비우면 다시 기본 명단이 채워집니다.

> **상위는 `이름 (등급)` 형식을 지켜 주세요.** 예: `루피 (초월)`
> 지츠다이스룰이 이 등급을 보고 초월/불멸/영원/제한별로 한 마리씩 뽑습니다.
> 등급이 없으면 "등급을 알아보지 못한 상위" 로 표시됩니다.
> **랜덤/콜라보** 는 등급 표기가 없어도 됩니다.

기본 명단은 `ropr/roster.py` 에 있습니다.

## 설정 파일 위치

- exe 옆의 `데이터\설정.json`
- 그 폴더에 쓸 수 없으면 (예: Program Files) `%APPDATA%\랜덤원피스룰\설정.json`

이 파일만 복사하면 다른 컴퓨터로 그대로 옮길 수 있습니다.
(방송 캡처에 사용자명이 노출되지 않도록, 프로그램 화면에는 경로를 표시하지 않습니다.)

## 개발

```
python -m unittest discover -s tests -v   # 뽑기 로직 테스트
```

| 파일 | 역할 |
|---|---|
| `main.py` | 실행 진입점 |
| `ropr/data.py` | 컨텐츠·강원랜디 기본 데이터, 검증 상태 |
| `ropr/config.py` | 설정 저장/불러오기 |
| `ropr/engine.py` | 뽑기 로직 (화면과 분리, 테스트 대상) |
| `ropr/roster.py` | 캐릭터 기본 명단 (전설·히든·상위·랜덤유닛) |
| `ropr/ui.py` | tkinter 화면 · 탭 구성 |
| `ropr/panels.py` | 버튼을 눌러서 뽑는 화면들 |
| `ropr/broadcast.py` | 방송 출력 창 (OBS 캡처용) |
| `ropr/sound.py` | 효과음 (WAV 를 직접 만들어 재생) |
| `ropr/images.py` | 등급 문양 · 유닛 그림 |
| `ropr/theme.py` | 색과 글꼴 |

컨텐츠를 추가하거나 룰을 고칠 때는 `ropr/data.py` 의 `CONTENTS` 에 항목을 넣고,
추가 뽑기가 필요하면 `ropr/engine.py` 에 `_follow_<id>` 를, 버튼 화면이 필요하면
`ropr/panels.py` 의 `PANELS` 에 패널 클래스를 등록하면 됩니다.
