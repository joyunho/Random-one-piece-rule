# Random-one-piece-rule

원피스 랜덤 룰 뽑기 프로그램 (윈도우 exe)

메인 컨텐츠를 뽑으면 그 컨텐츠에 딸린 **추가 뽑기까지 한 번에** 끝내 줍니다.

---

## exe 받는 방법

### 방법 1 — GitHub Actions 에서 받기 (파이썬 설치 필요 없음)

1. 이 저장소의 **Actions** 탭 → **build-exe** 워크플로 선택
2. 최근 실행 결과 클릭
3. 아래쪽 **Artifacts** 의 `랜덤원피스룰-exe` 다운로드 → 압축 풀면 `랜덤원피스룰.exe`

### 방법 2 — 내 컴퓨터에서 직접 만들기

1. [python.org](https://www.python.org/downloads/) 에서 파이썬 설치
   - 설치 첫 화면의 **Add python.exe to PATH** 를 반드시 체크
   - **tcl/tk and IDLE** 옵션도 켜져 있어야 합니다
2. 이 폴더를 내려받아서 `build_exe.bat` 더블클릭
3. `dist\랜덤원피스룰.exe` 완성

**창이 떴다가 바로 닫힌다면** — 창은 이제 에러 메시지를 띄우고 멈춥니다.
그래도 닫힌다면 폴더 주소창에 `cmd` 를 치고 엔터 → `build_exe.bat` 을 입력해서 실행하면
메시지가 남습니다. 빌드 중 오류는 같은 폴더의 `build_log.txt` 에 기록됩니다.

> `build_exe.bat` 은 **CRLF 줄바꿈 + 영문 전용**으로 되어 있어야 합니다.
> LF 로 저장되면 윈도우 cmd 가 `goto` 라벨을 못 찾아서 창이 그냥 닫힙니다.
> `.gitattributes` 에서 `*.bat -text` 로 고정해 두었습니다.

### 그냥 소스로 실행

```
python main.py
```

## 탭 설명

| 탭 | 하는 일 |
|---|---|
| **메인 뽑기** | 15개 메인 컨텐츠 중 하나를 뽑고, 추가 뽑기까지 진행 |
| **등급 뽑기** | 초월 / 불멸 / 영원 / 제한 / 신비 중에서 한 마리 (4명 각각도 가능) |
| **강원랜디** | 18개 확률표를 보면서 단독으로 돌리기 |
| **캐릭터 관리** | 전설 / 히든 / 상위 이름 목록 등록 |
| **설정** | 컨텐츠 on/off·가중치, 숫자 범위, 강원랜디 확률표 편집 |
| **기록** | 이번 판에 뽑은 내용 전부 보기 / 복사 / 파일 저장 |

## 메인 컨텐츠와 추가 뽑기

| 컨텐츠 | 추가 뽑기 |
|---|---|
| 스토리 폭격기전 | — |
| 원딜전(물1마1) | — |
| **4인 강제전** | 초·불·영·제 중 하나 |
| **지츠'다이스'룰** | 🎰 등급별 상위 1마리씩 + 색깔별 주사위(1~100) |
| 변질된 악몽 | — |
| **녜힁제조기** | 🎰 상위 이름에서 2글자 → 등급별 랜덤 픽 (아래 설명) |
| **인생의고도전** | 🎰 색깔별 `0~15`, [추가 고도] 로 `0~5` 자동 합산 |
| 신비한이세계전 | — |
| **너의상위는** | 🎰 색깔별 `0~4` (최대값이 뜨면 놀리는 소리) |
| **이캐릭들필수에요** | 🎰 전설 4칸 · 히든 4칸, 칸마다 버튼 |
| **이캐릭들금지에요** | 전설 7 + 히든 7 |
| **강원랜디** | 18개 확률표에서 하나 (숫자 범위가 있는 결과는 숫자도 같이) |
| 개인미션전 | — |
| 랜덤항법전 | — |
| **내가 제일 운 없어** | 🎰 색깔별 행운의 토큰, 제일 적은 사람 표시 |

> 🎰 표시가 붙은 컨텐츠는 **버튼을 하나씩 눌러서** 뽑습니다.
> 숫자·이름이 촤르륵 돌다가 효과음과 함께 멈춥니다. (효과음은 윈도우에서만 납니다)

### 내가 제일 운 없어

색깔별로 **행운의 토큰**(기본 0~5개)을 뽑습니다. 제일 적게 받은 사람이 "제일 운 없어".

행운의 토큰을 **쓰지 않고 클리어**하면, 가진 토큰 숫자만큼 **유카를 줄일 수 있습니다.**

토큰 개수 범위는 [설정] 탭에서 바꿀 수 있습니다.

### 녜힁제조기

1. 상위 이름에 들어 있는 글자 중에서 **2글자**를 뽑는다
2. 그 글자가 이름에 포함된 **상위를 전부** 보여준다 (2마리를 넘어도 다 나옴)
3. 그 중에서 **초월 / 불멸 / 영원 / 제한 각 등급별로 한 마리씩** 랜덤으로 뽑는다

글자 2개와 등급별 픽 모두 각각 버튼입니다. 주사위는 없습니다.

> 예) `로`, `규` 가 나오면 → `로쿠규초월`, `로우초월` 처럼
> 이름에 `로` 나 `규` 가 들어간 상위만 사용

최소 한 마리는 나와야 하므로 **[캐릭터 관리] 탭에 등록한 상위 이름에 실제로 들어 있는 글자만** 후보가 됩니다.
`초월/불멸/영원/제한/신비` 같은 등급 글자는 뽑기 후보에서 제외됩니다
(안 그러면 `초` 하나로 초월 전부가 걸리기 때문). 이 제외 목록은 [설정] 탭에서 바꿀 수 있습니다.

등급별 랜덤 픽은 **상위 이름에 등급이 들어 있는 것**으로 판단합니다
(`로쿠규초월` → 초월). 해당 등급에 걸린 상위가 없으면 `(해당하는 상위 없음)` 으로 표시됩니다.

### 인생의고도전

색깔마다 카드가 하나씩 있고, **[고도 뽑기]** 로 `0~15` 를 뽑습니다.
이어서 **[추가 고도]** 를 누르면 `0~5` 가 나와서 **기존 고도에 자동으로 더해집니다.**
옆의 세로 막대(기구)가 고도만큼 올라갑니다.

### 효과음과 그림

- 효과음은 **윈도우에서만** 납니다. 외부 파일 없이 프로그램이 직접 소리를 만듭니다.
  메인 뽑기 화면의 **[효과음]** 체크로 끌 수 있습니다.
- 등급 문양은 프로그램이 직접 그립니다. 유닛 그림을 쓰고 싶으면
  설정 파일 옆에 `이미지` 폴더를 만들고 `루피.png` 처럼 넣어두면 자동으로 붙습니다.
  (`루피 (초월).png` 처럼 등급까지 붙인 이름도 인식합니다)

## 캐릭터 명단

**기본 명단이 이미 들어 있습니다.** 처음 켜도 바로 돌아갑니다.

| 목록 | 개수 | 쓰이는 곳 |
|---|---|---|
| 전설 | 39 | 이캐릭들필수 / 이캐릭들금지 |
| 히든 | 16 | 이캐릭들필수 / 이캐릭들금지 |
| 상위 | 88 | 녜힁제조기 (초월 39 · 불멸 13 · 영원 12 · 제한 11 · 신비 13) |

**[캐릭터 관리] 탭**에서 언제든 고치고 **저장**하면 됩니다. 한 줄에 이름 하나씩이고,
고친 내용이 기본 명단보다 우선합니다. 목록을 통째로 비우면 다시 기본 명단이 채워집니다.

> **상위는 `이름 (등급)` 형식을 지켜 주세요.** 예: `루피 (초월)`
> 녜힁제조기가 이 등급을 보고 초월/불멸/영원/제한별로 한 마리씩 뽑습니다.
> 등급이 없으면 "등급을 알아보지 못한 상위" 로 표시됩니다.

기본 명단은 `ropr/roster.py` 에 있습니다.

## 설정 파일 위치

- exe 옆의 `데이터\설정.json`
- 그 폴더에 쓸 수 없으면 (예: Program Files) `%APPDATA%\랜덤원피스룰\설정.json`

프로그램 아래쪽 상태 표시줄에 실제 경로가 나옵니다.
이 파일만 복사하면 다른 컴퓨터로 그대로 옮길 수 있습니다.

## 개발

```
python -m unittest discover -s tests -v   # 뽑기 로직 테스트
```

| 파일 | 역할 |
|---|---|
| `main.py` | 실행 진입점 |
| `ropr/data.py` | 컨텐츠·강원랜디 기본 데이터 |
| `ropr/config.py` | 설정 저장/불러오기 |
| `ropr/engine.py` | 뽑기 로직 (화면과 분리, 테스트 대상) |
| `ropr/roster.py` | 캐릭터 기본 명단 |
| `ropr/ui.py` | tkinter 화면 · 탭 구성 |
| `ropr/panels.py` | 버튼을 눌러서 뽑는 화면들 |
| `ropr/sound.py` | 효과음 (WAV 를 직접 만들어 재생) |
| `ropr/images.py` | 등급 문양 · 유닛 그림 |
| `ropr/theme.py` | 색과 글꼴 |
