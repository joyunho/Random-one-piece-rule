# Random-one-piece-rule

원피스 랜덤 룰 뽑기 프로그램 (윈도우 exe)

메인 컨텐츠를 뽑으면 그 컨텐츠에 딸린 **추가 뽑기까지 한 번에** 끝내 줍니다.

---

## exe 받는 방법

### 방법 1 — GitHub Actions 에서 받기 (파이썬 설치 필요 없음)

1. 이 저장소의 **Actions** 탭 → **build-exe** 워크플로 선택
2. 최근 실행 결과 클릭
3. 아래쪽 **Artifacts** 의 `랜덤원피스룰-exe` 다운로드 → 압축 풀면 `랜덤원피스룰.exe`

### 방법 2 — 내 컴퓨터에서 직접 만들기

1. [python.org](https://www.python.org/downloads/) 에서 파이썬 설치
   (설치 화면에서 **tcl/tk** 옵션이 켜져 있어야 합니다)
2. 이 폴더를 내려받아서 `build_exe.bat` 더블클릭
3. `dist\랜덤원피스룰.exe` 완성

### 그냥 소스로 실행

```
python main.py
```

## 탭 설명

| 탭 | 하는 일 |
|---|---|
| **메인 뽑기** | 14개 메인 컨텐츠 중 하나를 뽑고, 추가 뽑기까지 자동으로 진행 |
| **등급 뽑기** | 초월 / 불멸 / 영원 / 제한 / 신비 중에서 한 마리 (4명 각각도 가능) |
| **강원랜디** | 18개 확률표를 보면서 단독으로 돌리기 |
| **캐릭터 관리** | 전설 / 히든 / 상위 이름 목록 등록 |
| **설정** | 컨텐츠 on/off·가중치, 숫자 범위, 강원랜디 확률표 편집 |
| **기록** | 이번 판에 뽑은 내용 전부 보기 / 복사 / 파일 저장 |

### 녜힁제조기

상위 이름에 들어 있는 글자 중에서 **2글자**를 뽑고,
그 글자가 이름에 포함된 상위만 써서 클리어하는 룰입니다.

> 예) `로`, `규` 가 나오면 → `로쿠규초월`, `로우초월` 처럼
> 이름에 `로` 나 `규` 가 들어간 상위만 사용

최소 한 마리는 나와야 하므로 **[캐릭터 관리] 탭에 등록한 상위 이름에 실제로 들어 있는 글자만** 후보가 됩니다.
`초월/불멸/영원/제한/신비` 같은 등급 글자는 뽑기 후보에서 제외됩니다
(안 그러면 `초` 하나로 초월 전부가 걸리기 때문). 이 제외 목록은 [설정] 탭에서 바꿀 수 있습니다.

## 처음 실행하면 할 일

**[캐릭터 관리] 탭**에서 세 가지 목록을 채워 주세요. 한 줄에 이름 하나씩입니다.

- **전설** — 이캐릭들필수/금지에서 뽑습니다
- **히든** — 이캐릭들필수/금지에서 뽑습니다
- **상위** — 녜힁제조기의 글자 뽑기에 씁니다

**저장**을 누르면 설정 파일에 저장되고, 다음에 켤 때 그대로 남아 있습니다.

## 설정 파일 위치

- exe 옆의 `데이터\설정.json`
- 그 폴더에 쓸 수 없으면 (예: Program Files) `%APPDATA%\랜덤원피스룰\설정.json`

프로그램 아래쪽 상태 표시줄에 실제 경로가 나옵니다.
이 파일만 복사하면 다른 컴퓨터로 그대로 옮길 수 있습니다.

| `ropr/engine.py` | 뽑기 로직 (화면과 분리, 테스트 대상) |
| `ropr/ui.py` | tkinter 화면 |
